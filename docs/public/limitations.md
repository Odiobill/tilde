# Limitations

One globally unsettled run is deliberate. Pending approvals, budget pauses,
blocked recovery and unknown outcomes prevent unrelated new work. There are zero
automatic provider retries and no blind replay of uncertain effects. Cancellation
is not rollback and cannot contain work delegated to independent services.

Typed files require supported local Linux storage with openat2/renameat2 and safe
ownership/modes. Symlink/hardlink/unsupported metadata targets are refused. A
rename is not a transaction across derived stores, or CAS against arbitrary
external writers. Process-kill/SQLite tests do not certify physical power-loss
or every filesystem/cache. Qualified guest storage-loss evidence has its own scope.

Compositors control focus, placement and global shortcuts. An activation ACK or
offscreen window-ready event is not actual focused input. Plasma Wayland's
historical Qt 6.8.2 focus failure remains unresolved. For this candidate the owner
explicitly deferred Plasma Wayland/X11 sessions, actual assistive-technology
acceptance and the remaining installed manual walkthrough to a later update.
Positive owner feedback covers visual/Settings review only. These are scoped
exceptions, not passing tests or desktop/accessibility compatibility claims.
Hyprland and reference performance observations retain their recorded source and
measurement limits. The real local-model trial was also explicitly skipped because
no local server/model was available; synthetic provider coverage remains required.

The first release excludes Computer Use, production CodeMode, a root helper,
privileged/system/package/desktop action adapters, parallel work, a web view,
telemetry and automatic updates. Bundled SDK transitive modules do not enable
these features. There is no guarantee for every provider, desktop or future Node
major. Use the final artifact's actual tested matrix and retained limitations.
