# Reporting a security issue

Use [GitHub private vulnerability reporting](https://github.com/Odiobill/tilde/security/advisories/new).
Do not post provider keys, credential files or private transcripts in public
issues. If the private route is unavailable, ask for a private contact in a public
issue without describing sensitive details, then wait for the maintainer.

Include version/environment and a minimal synthetic reproduction. Read the
[security boundaries](docs/public/security.md) and
[known limitations](docs/public/limitations.md). No response-time commitment is
implied. An approved unrestricted shell has your ordinary account's authority;
typed filesystem roots do not sandbox it.
